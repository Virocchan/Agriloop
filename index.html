⚙️ Bin Firmware State Machine

IDLE

Lid locked. TFT shows QR with rotating nonce every 30s.

→
UNLOCK_PENDING

MQTT unlock cmd received. Takes "before" photo, unlatches lid, 30s timer.

→
OPEN

Lid opened. Records weight_before. Green LED glow.

→
SETTLING

Reed switch detects closed lid. Relocks. Waits for std dev < 5g over 1.5s.

→
CAPTURE & UPLOAD

Takes "after" photo. HTTPS POST to n8n with HMAC signature.
